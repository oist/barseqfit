## Extraction rule

- Genotype id (`sequence_id`) is the 9-nt SV, `substr(amplicon, 52, 60)`.
- Keep only genotypes present in the `M9+TMP` (after) matrix, aligning `before` and `after` by SV (mirrors the authors' `before2` filter).
- Sample 10 rows at random from `fitness_diff_wald_test_data.RDS` (restricted to pairs whose genotypes are both in the after matrix), keeping the published orientation (`from`, `to`).
- Subset genotypes: WT `GCCGATCTC` plus the union of `from` and `to` (21 genotypes).
- No filtering on zero counts or fitness values.

## Files

- `counts.csv`: `sequence_id, sample_id, count`; long format, 12 samples x 21 genotypes, zeros kept. `sample_id` is `before_F01..F06` and `after_F01..F06`.
- `samples.csv`: `sample_id, condition` (`M9+TMP`), `replicate_id` (`F01..F06`), `time` (0 before, 3.5166197103891137 after), `sample_total`. `sample_total` is the per-sample row sum of the full unfiltered count matrix over all genotypes, computed before any subsetting (before: all 261,378 genotypes; after: all 261,333). It counts mapped reads only; no `Total_Nreads` column exists in the store. `time` is numeric time in generations (used directly by the fits). The generation time is the value recovered as recorded in `docs/validation.md` (Generation time); the validation script cross-checks the totals against the store, and the combination reproduces the published tables to about 1e-14 when combined with these totals; the rounded 3.51662 only reaches about 1e-7.
- `sequences.csv`: `sequence_id, sequence` (the 9-nt SV).
- `pairs.csv`: `from, to` in the published orientation.
- `expected_wt.csv`: `sequence_id, m, se, p` from `fitness_data_wt.rds` (`m`, `m_se`, `m_p.value`); the WT row has `m = 0` and empty `se`, `p`.
- `expected_pair.csv`: `from, to, m, se, p` from `fitness_diff_wald_test_data.RDS` (`m`, `m_se`, `m_p.value`).
- `expected_{wt,pair}_padj_r.csv`: R's BH `p_adj` (default dispersion), from `scripts/make_padj_expected.R` (`just make-padj-expected`).

Numbers are written with 17 significant digits; missing values are empty.
